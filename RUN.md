# Запуск

## Требования

- Python ≥ 3.11
- Только стандартная библиотека (без pip-зависимостей)

## Команды

Из каталога `candidate-B/`:

```bash
python3 -I report.py --data data --date 2026-11-10
python3 -I report.py --data data --date 2026-11-10 --csv out.csv
python3 -I -m unittest discover -s tests -t .
```

## Что выводится

- **stdout:** отчёт на дату — таблицы «Работы», «Договоры», «Платежи».
- **stderr (после отчёта):** блок «Предупреждения:», если есть расхождения или дата отчёта позже данных.
- **`--csv out.csv`:** `out.csv` (работы и договоры) и рядом `out_payments.csv` (платежи). Разделитель `;`, UTF-8 с BOM. Путь CSV не должен лежать внутри `--data`.

## Что осталось / что бы сделал дальше

- Флаг CLI для смены стратегии распределения аванса (сейчас FIFO по приёмке зашит в одной функции).
- Отдельный файл ручной привязки платежей к работам, если бухгалтер задаёт соответствие вне учёта.
- Учёт частичных возвратов, если появятся в выгрузке (сейчас возврат целиком исключает платёж).
- Явная пометка платежей «вне сметы» (материалы, доплаты), чтобы не смешивать их с ценой работ без решения бухгалтера.
